# 鹈鹕骑士 · Pelican Rider

海鸥帮抢走了镇上的黄金大鱼。戴风镜的鹈鹕骑上单车，沿着海岸公路一路追。

在线玩：https://hitanorain.github.io/pelican-rider/

## 玩法

- `A` `D` / `←` `→` 转向，`W` / `↑` 跳跃
- 空格 / 鼠标左键：从嘴里吐鱼，打前面骑滑板车的海鸥
- `Shift`：辣椒氮气，加速时能撞飞敌人、冲破障碍
- `P` 暂停，`M` 静音；手机上拖动转向，右下角有按钮
- 每段路的尽头要打掉海鸥老大的押运车；打完三个通关，之后是无尽模式

## 技术

单文件 `index.html`，three.js 0.170（ES 模块，从 jsDelivr 加载）。模型、贴图、音效和音乐都在代码里生成，没有外部素材。

本地运行：在这个文件夹里起一个静态服务器，例如 `python -m http.server 8791`，然后打开 http://localhost:8791/ 。
